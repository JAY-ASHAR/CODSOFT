# Customer Churn Prediction

## Task Description
This project focuses on predicting customer churn for a subscription-based service using supervised machine learning techniques.

## Objective
To build a classification model that can predict whether a customer is likely to leave the service based on historical customer data.

## Dataset
The dataset contains historical customer information including demographic details, account-related features, and churn status.

## Approach
- Data loading and analysis using Pandas and NumPy
- Data visualization using Matplotlib and Seaborn
- Encoding categorical variables using LabelEncoder
- Splitting the dataset into training and testing sets
- Model training using supervised classification algorithms
- Model evaluation using accuracy, precision, recall, F1-score, confusion matrix, and classification report

## Tools & Libraries
- Pythona
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

## Outcome
The model predicts customer churn with reliable performance, providing insights that can help businesses take proactive retention measures.
