# Movie Genre Classification

## Task Description
This project focuses on classifying movies into different genres based on their plot descriptions using machine learning techniques on textual data.

## Objective
To build a machine learning model that can predict the genre of a movie from its plot description.

## Dataset
The dataset consists of movie plot summaries along with their corresponding genre labels.

## Approach
- Reading and parsing raw text data using Python file handling
- Basic text cleaning using regular expressions
- Feature extraction using TF-IDF Vectorization
- Model training using Multinomial Naive Bayes
- Performance evaluation using accuracy and classification report

## Tools & Libraries
- Python
- Pandas
- NumPy
- Scikit-learn
- os
- re

## Outcome
The model is able to classify movie genres from text data with reasonable accuracy.
